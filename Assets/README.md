# VR-сцена с предметами и пространственным звуком

На небольшой летающей площадке можно перемещаться телепортом, брать и бросать предметы из металла, дерева и стекла. Столкновения предметов сопровождаются позиционным звуком через Steam Audio.

## Версии и зависимости

- Unity: **6000.3.17f1 LTS**
- Universal Render Pipeline: **17.3.0**
- XR Interaction Toolkit: **3.6.1**
- OpenXR: **1.18.0**
- Input System: **1.20.1**
- Пространственный звук: [Steam Audio](https://valvesoftware.github.io/steam-audio/downloads.html)

## Запуск

1. Откройте проект в Unity **6000.3.17f1 LTS**.
2. Откройте сцену `Assets/Scenes/Testscene.unity`.
3. Запустите Play Mode.
4. Для проверки без VR-шлема используется sample **XR Interaction Simulator** из XR Interaction Toolkit.

## Что сделано

- Собрана компактная сцена с моделью летающего острова и игровой площадкой 10 × 10 м.
- На площадке настроена область телепортации.
- Добавлены шесть интерактивных предметов: молот, меч, бочка, ящик, красный и синий флаконы. У предметов есть Rigidbody, коллайдеры и XR Grab Interactable.
- Использованы три группы звуков столкновений: металл, дерево и стекло.
- Steam Audio выбран в настройках проекта как Spatializer; источники звука предметов настроены как пространственные.
